# Portfolio Edition

This repository is a sanitized public representation of a workforce scheduling system.

Before publication, the portfolio edition:

- replaced employee names and schedules with synthetic demo identities;
- removed one-off production migration rules tied to named employees and dates;
- removed the hard-coded administrator password;
- removed production database paths and automatic private-directory discovery;
- excludes runtime databases, backups, session tokens and generated network-access files.

The scheduling engine, role-based access, auditing, backups, break reminders, team management, department switching and update architecture remain represented.
